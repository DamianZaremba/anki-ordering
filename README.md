Anki Ordering Template
=======================

Card template for Anki for sequence/ordering quizzes - arrange a list of steps or items into the correct order.

Features:
- Any number of items (stored as a JSON `Items` field, in correct order)
- Front side shuffles the items and lets you reorder them with up/down controls; back side marks each position correct/wrong

# Installation

There are 2 options for installation:

1. Clone this repo and execute scripts/sync-database.py (will update an existing entry)
2. Import the ordering.apkg file from a release
